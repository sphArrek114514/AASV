# AASV原子结构可视化
#（全称Arrek-studio Atomic Structure Visualization Program）

## 项目概述
这是一个功能丰富的原子结构可视化与化学学习工具，旨在帮助学生更直观地了解原子结构、周期律以及进行互动学习。

## 使用方法
1. 在标签中下载最新版本（版本命名规则：v总版本编号-年份m月份.该月版本编号，想找到最新版本就看总版本编号；还有一个方案是以当前版本号对应的元素命名，比如v4即铍）
2. 直接在浏览器中打开文件即可使用
3. 无需安装任何软件，支持所有现代浏览器
4. 建议使用 Chrome、Firefox 或 Edge 浏览器获得最佳体验

## 主要功能

- **原子结构图**：创造性地使用8个原点展示最外层电子排布，方便解释和理解各元素化学性质
- **元素信息展示**：点击属性按钮展示详细信息，包括原子序数、符号、名称、相对原子质量、密度、原子半径等
- **元素周期表**：完整的元素周期表，支持点击跳转、高亮定位和特点元素种类高亮显示
- **UI设计**：极简风格，黑色为主、紫色为辅，其余颜色点缀其间
- **小游戏**：各种好玩的小游戏！


## 技术说明
- 基于 HTML5、CSS3 和 JavaScript 开发
- 纯前端实现，无需后端服务器
- 收藏和游戏数据本地存储，支持离线使用
- 模块化代码结构，易于维护和扩展
